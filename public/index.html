Les commandes et les conseils de démarrage +

Castle Wolfenstein : Entrée au titre, puis K. Flèches ou ZQSD pour déplacer le personnage ; O / K / ; / virgule pour viser haut / gauche / droite / bas. I / P / M / point pour les diagonales. Espace pour tirer, E pour fouiller, T pour la grenade et U pour utiliser un coffre.

Choplifter : Entrée pour décoller ; flèches ou ZQSD pour voler ; J / K / L pour orienter gauche / face / droite ; Espace pour tirer ; P pour pause et M pour le son. Les touches 1 et 2 sélectionnent le mode au menu.

Zany Golf : cliquez sur le terrain pour viser, maintenez Espace pour doser, puis relâchez pour tirer. E ou le bouton Action active les mécanismes du parcours ; flèches gauche et droite pour le flipper ; P pour pause, M pour le son, F pour le plein écran et Échap pour annuler un tir. La partie se sauvegarde automatiquement.

Les jeux sont conçus pour ordinateur, avec clavier et souris. Utilisez Plein écran pour agrandir l’image. Les sauvegardes sont locales à ce navigateur et ne se synchronisent pas entre appareils.
